# Favicon Design Options för licod.io

## Nuvarande (din):
```svg
Svart bakgrund + vit $ symbol
```
**Fördelar**: Enkelt, tydligt
**Kan förbättras**: Positionering, typsnitt

---

## Option 1: Förbättrad $ (rekommenderad)
**Ändringar**:
- Bättre positionering
- Optimalt för små storlekar
- Monospace-font garanterad

**Preview**: Svart ruta med centrerad vit $

---

## Option 2: Terminal-prompt >_
**Design**:
- Grön text (#0f0) på svart (#000)
- Klassisk hacker-känsla
- Mycket tech

**Preview**: Svart ruta med grön >_

---

## Option 3: Gradient $
**Design**:
- Gradient från grön till cyan
- Modern look
- Fortfarande läsbar i liten storlek

**Preview**: Svart ruta med färgglad $

---

## Option 4: Minimalistisk box
**Design**:
- Bara en outline-box med $ inuti
- Mycket clean
- Modern

**Preview**: Vit outline på svart

---

## Rekommendation:

För **licod.io** passar bäst:
1. Option 1 (förbättrad $) - professionell, ren
2. Option 2 (>_) - mer terminal-känsla
3. Nuvarande - redan bra!

**Tips**: Testa hur de ser ut i:
- Browser tab (16x16px)
- Mobil hemskärm (192x192px)
- Desktop app icon (512x512px)
