# Agent Guidelines for Linux Command Of the Day

## Build/Run Commands
- No build step required - static HTML/CSS/JS project
- Serve locally: `python3 -m http.server 8000` or open `index.html` in browser
- Generate data: `./create_commands.sh && ./collect_en.sh`
- No linting or test commands - no test suite exists

## Code Style
- **JS**: ES6+ vanilla JavaScript, no frameworks. `const`/`let`, arrow functions, template literals
- **HTML**: Semantic HTML5, simple structure
- **CSS**: Global styles in `style.css`, BEM-like naming (`.nav-command`, `#command-name`)
- **Formatting**: 2-space indentation, no semicolons in JS
- **Naming**: camelCase for JS vars/functions (`todayIndex`, `renderDay`)
- **Error handling**: Minimal - promises with `.then()`, basic bash checks with `[ ]`
- **Bash**: `#!/usr/bin/env bash`, exit on errors
- **Data**: Linux commands as `.md` in `data/`, JSON generated by `collect_en.sh`

## Project Structure
- `index.html` - Main app entry point
- `script.js` - Daily command rotation and rendering logic
- `style.css` - Responsive styling with gradients
- `data/*.md` - Command documentation files
- `commands_en.json` - Generated JSON data feed
- `create_commands.sh` - Generates markdown from man pages
- `collect_en.sh` - Parses markdown into JSON
