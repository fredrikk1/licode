# Agent Guidelines for Linux Command Of the Day

## Build/Run Commands
- No build/lint/test tooling - vanilla static HTML/CSS/JS project
- Serve locally: `python3 -m http.server 8000` or open `index.html` in browser
- Generate data: `./create_commands.sh && ./collect_en.sh` (requires Python 3)
- No test runner - no test suite exists

## Code Style
- **JS**: ES6+ vanilla (no frameworks/modules). Use `const`/`let`, arrow functions, template literals
- **Imports**: No imports - single `script.js` file. Data loaded via `fetch('commands_en.json')`
- **Types**: No TypeScript - plain JS with JSDoc comments for complex functions only
- **Formatting**: 2-space indentation, no semicolons. Single quotes, trailing commas optional
- **Naming**: camelCase (`todayIndex`, `shuffleArray`), descriptive global vars, no abbreviations
- **HTML**: Semantic HTML5, minimal. IDs for unique elements (`#command-name`, `#today-btn`), classes for styles
- **CSS**: Global styles only in `style.css`, no scoped/CSS-in-JS. Descriptive classes (`.nav-command`, `.example-desc`)
- **Error handling**: Minimal - use `.then()/.catch()` for promises, inline `if` checks for bash
- **Bash**: `#!/usr/bin/env bash` shebang, quote variables, exit on error, no fancy syntax

## Data Structure
- Commands: `.md` files in `data/` with sections: `# name`, description, `## Examples`, `## Pro tip`
- JSON feed: `commands_en.json` (autogenerated, never edit manually) - format: `{name, description, examples: [{cmd, desc?}], protip}`
- Rotation: Seeded shuffle (seed: 12345) based on UTC days since 2025-01-01

## Project Structure
- `index.html` - Entry point, PWA manifest meta tags
- `script.js` - Command fetching, shuffle/rotation logic, DOM rendering, share/copy handlers
- `style.css` - Responsive design (mobile breakpoint 767px), PWA styling
- `data/` - 42 command markdown files
- `create_commands.sh` - Bash script that generates `data/*.md` files
- `collect_en.sh` - Python3 script converts `data/*.md` → `commands_en.json`
